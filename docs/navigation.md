## Navigation

When you launch Astrofox you will be presented with this screen.

<img class="img-fluid" src="/images/docs/navigation.png" />

The navigation elements shown above are:

### 1. Menu bar

This is where you can access all file and application commands. 

### 2. Stage

The stage is where your displays and effects will appear.

### 3. Control dock

The control dock contains inputs for controlling elements on the stage. The layers panel allow you to compose
different layers of visual elements and the controls panel lets you manipulate each visual element.

### 4. Audio player

This is where you control the audio after you've loaded an audio file.

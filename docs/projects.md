## Projects

You can save and load your work in Astrofox as project files. They will be saved with the extension `.afx`. 

### Saving a project

Click on **Menu > File > Save Project** or **Menu > File > Save Project As**. 

### Opening a project

Click on **Menu > File > Open Project** and browse to your previously saved project file.

### Starting a new project

Click on **Menu > File > New Project**. If you have any unsaved changes, you will be prompted to save your
changes before continuing. If you choose not to save, your unsaved changes will be discarded.

### What gets saved

Project files only contain the settings of any displays, effects, and the stage. Any audio you loaded is not saved
with the project file. This allows you to reuse projects for different audio files.

Any images loaded will be saved along with the project.

## Stage

The stage is where all your visual elements are displayed and what will be finally rendered to video.

<img class="img-fluid" src="/images/docs/stage.jpg" />


### Resize canvas

The default stage canvas size is **854x480**.

To resize the canvas, go to **Menu > Edit > Canvas** and select new dimensions.

#### Zooming

You can also zoom in and out of the stage by using **Menu > View > Zoom In/Out** or by clicking
the zoom controls in the status bar. Note that this only provides a visual change. It does not change
the actual size of the canvas.

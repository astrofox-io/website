## Getting started

Welcome to the Astrofox documentation! Here you will find helpful instructions on how to use Astrofox.

Choose a topic from the menu on the left to get started.

### System requirements

Astrofox runs on Windows 7+, MacOS 10.10+ (Yosemite or newer) and Linux (Ubuntu
12.04+, Fedora 21, Debian 8). You will need a video card capable of running [WebGL](https://get.webgl.org).
